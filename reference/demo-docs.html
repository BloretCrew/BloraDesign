绑定自定义域名

适用于所有套餐 · 阅读约 6 分钟 · 11 月 22 日更新

On this page
阅读进度约 6 分钟
0

把 app.example.com 这样的自有域名指向 Blora 上的实例后，访问者看到的就是你的品牌域名。HTTPS 证书由 Blora 自动签发，并在到期前自动续期，不需要手动上传。

概述

每个实例默认带有一个 *.blora.app 的二级域名。绑定自定义域名不会替换它，两个地址会同时可用；你可以在设置里把默认域名 301 跳转到自定义域名。

  • 每个实例最多绑定 20 个域名，团队版可以申请提高上限。
  • 支持通配符域名，例如 *.preview.example.com，适合为每个分支生成独立的预览地址。
  • DNS 生效通常只需要几分钟，个别注册商最长可能需要 48 小时。

准备工作

  1. 确认你有域名 DNS 的管理权限，能够添加 CNAME、A 和 CAA 记录。
  2. 在控制台打开目标实例，进入设置 › 域名，点击添加域名。
  3. 如果域名之前接入过其他平台，先删除旧的 CNAME 记录，避免解析冲突。

添加 DNS 记录

根据你要绑定的是子域名还是根域名，选择对应的记录类型。下表列出了最常见的几种情况：

场景类型主机记录记录值TTL
子域名CNAMEappedge.blora.app600
根域名A@76.223.18.40600
根域名（IPv6）AAAA@2600:1f18::40600
证书授权CAA@0 issue "letsencrypt.org"3600

子域名（推荐）

子域名使用 CNAME 记录指向 edge.blora.app，Blora 会根据访问者所在区域自动选择最近的边缘节点。添加记录后，可以用下面的命令确认解析是否已经生效：

bash
# 应该返回 edge.blora.app.
$ dig +short app.example.com CNAME
# 也可以用 CLI 立即触发一次校验
$ blora domains verify app.example.com --instance web-edge-03
提示

修改记录前先把 TTL 调低到 600 秒，出问题时可以更快地切回旧配置；确认稳定后再改回 3600。

根域名 apex

大多数 DNS 服务商不允许在根域名上使用 CNAME。这种情况下请添加 A 记录（以及可选的 AAAA 记录），或者使用服务商提供的 ALIAS / ANAME 记录指向 edge.blora.app。

如果希望 example.com 和 www.example.com 都能访问，建议把其中一个设为主域名，另一个在控制台里配置 301 跳转，避免搜索引擎把它们当成两个站点。

签发 HTTPS 证书

DNS 生效后，Blora 会自动向 Let's Encrypt 申请证书，整个过程通常在 1 分钟内完成。证书有效期 90 天，到期前 30 天自动续期，续期失败时会给工作区管理员发送邮件。

注意

如果域名设置了 CAA 记录，但没有包含 letsencrypt.org，证书会一直停留在“签发中”。请按上表补充 CAA 记录，然后在控制台点击重新签发。

  • 证书签发期间，HTTP 请求正常返回，HTTPS 请求会暂时使用默认证书。
  • 需要使用自有证书（例如 EV 证书）时，可以在域名 › 高级里上传 PEM 格式的证书链与私钥。
