# @bloret-crew/blora-design

Blora Design 3.0 主包：一份 CSS（`blora.css`）加一个自动接管页面的运行时（`blora.js`）。

> `3.0.0-alpha`：开发中，接口会变。规范、写法和进度见 [BloretCrew/BloraDesign](https://github.com/BloretCrew/BloraDesign)。

```bash
npm install @bloret-crew/blora-design
```

```js
import '@bloret-crew/blora-design/blora.css';
import '@bloret-crew/blora-design';
```
